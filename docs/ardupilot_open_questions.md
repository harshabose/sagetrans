same tree: 4.7.0 (21 Jul 2026), 4.7.1 (31 Aug 2026), 4.7.2-beta1 (29 Sep 2026).

| O-08 | ANSWERED (decision still yours) | Both gain schemes exist in master. `get_vfwd_method()`: NEW (`Q_FWD_THR_GAIN`, default 2.0) is used if gain > 0 and (aux switch, or `Q_FWD_THR_USE`=2, or =1 with position control active); else OLD (`Q_VFWD_GAIN`) if > 0 and position control active; else none. `Q_FWD_THR_USE` defaults to OFF. | Pin a Plane-4.7.x tag; re-run this table against it. With defaults (USE=0) neither scheme is active in the back-transition and the pusher is off. |
| O-01 | ANSWERED | `do_vtol_land()` (NAV_VTOL_LAND) calls `poscontrol_init_approach()`, as does QRTL. Both use APPROACH → AIRBRAKE → POSITION1 → POSITION2. Shortcuts: `DISABLE_APPROACH` option or `Q_APPROACH_DIST` ⇒ straight to POSITION1; if `dist < transition_threshold` ⇒ AIRBRAKE (or POSITION1 if VTOL motors already running). QRTL within 1.5·max(loiter radius, RTL_RADIUS) with motors running ⇒ POSITION1. | AUTO and QRTL landings share logic. D must model APPROACH → AIRBRAKE → POSITION1, not a direct cruise → Position1 switch. |
| O-02 | ANSWERED | Switch test uses **ground speed**: `stopping_distance_m()` = \|groundspeed vector\|² / (2·`Q_TRANS_DECEL`). APPROACH → AIRBRAKE (or POSITION1 if VTOL motors already spooled) when `wp_distance < stopping_distance + 2·closing_speed` (a 2 s margin). | Repo eq. (8.11) `d ≤ V²/(2a)` omits the `+ 2·V_closing` term (≈ +50 m at 25 m/s). The `speed_test="air"` option is not ArduPilot behaviour. Fix `BaselineController` and `landing_error`. |
| O-03 | ANSWERED | AIRBRAKE (entered when VTOL motors are off): motors spool up, `hold_hover(0)` (Z controller, zero climb rate, integrator reset to 0 on entry); fixed-wing nav continues with pusher throttle and pitch from TECS, pitch clamped ≥ 0; `active_frwd()` is false. Minimum 1 s. Exit to POSITION1 after 1 s if any of: airspeed < max(AIRSPEED_MIN−2, Q_ASSIST_SPEED); closing-velocity direction > 60° off; closing speed > max(1.2·desired, desired+2); closing speed < 0.5·desired; roll or pitch error > 10°. On exit `set_last_fw_pitch()` starts the pitch-envelope clock. | Position1 entry speed is about max(AIRSPEED_MIN−2, assist speed), not cruise speed, unless the profile is violated. D's entry-speed grid should be re-centred. The pusher is not "off at entry"; it is TECS-driven in AIRBRAKE. |
| O-04 | ANSWERED | `Q_TRANSITION_MS` (clamped 500–30000 ms), timer starts when airspeed > AIRSPEED_MIN and assistance is off. TIMER state: `hold_stabilize(throttle_scaled)` with `throttle_scaled = last_throttle · (T − t)/T`, floor 0.01 until DONE, then spool SHUT_DOWN. `last_throttle` is frozen at the end of the airspeed wait. Throttle mix 0.5·scale. The fade is **linear and open-loop**, no altitude hold. `Q_BACKTRANS_MS`: upper pitch limit = interpolate(max(last_fw_nav_pitch,0) → min(Q_A_ANGLE_MAX, PTCH_LIM_MAX_DEG)) over T; lower limit = interpolate(min(last_fw_nav_pitch,0) → max(−Q_A_ANGLE_MAX, PTCH_LIM_MIN_DEG)); envelope off once dt > T. | Repo's `fwd_fade` keeps altitude hold during the fade and scales its output; ArduPilot freezes the throttle and fades open-loop. The pitch ramp starts at the last FW nav pitch (≥ 0), not at 0, and there is a nose-down envelope too. Pitch is also always limited ≤ Q_A_ANGLE_MAX on roll and nose-down. |
| O-05 | ANSWERED | `Q_BCK_PIT_LIM` (default 10°): applied only when `get_vfwd_method()==NEW`. `limit = min(Q_BCK_PIT_LIM · (max(AIRSPEED_MIN,5)/EAS)², Q_A_ANGLE_MAX)`, EAS floored at 0.1; value ≤ 0 disables. | Not a constant cap. Example (Vmin 14): 25 m/s → 3.1°, 18 m/s → 6.0°. `theta_B` must become `θ_B0 (V_min/V)²`, active only when the NEW scheme is on. Large effect on braking distance. |
| O-06 | PARTIAL | Spool-up goes through `AP_Motors` with `MOT_SPOOL_TIME` default 0.5 s (zero → min throttle, then min → full, linear in `dt/spool_time`). `MOT_SPIN_MIN` default 0.15. | Add a ~0.5 s rotor lag when rotors start from SHUT_DOWN (AIRBRAKE entry). Repo's `delta_min=0.1` placeholder differs from the 0.15 default. Prefix for Sage's actual params is `Q_M_`. |
| O-07 | PARTIAL | Surfaces keep running in every state. In AIRSPEED_WAIT the plane pitch/roll integrators are reset each step. VTOL angle-P gains (POSITION1) blend from MC to FW gains linearly with EAS between 3 m/s and AIRSPEED_MIN. No explicit scaling of surface deflection by VTOL throttle was found. Surface speed scaling lives in the fixed-wing controllers (not read). | Surface pitch moment remains a model assumption; calibrate in the attitude surrogate from logs. |

| O-10 | PARTIAL | `TECS_THR_ERATE` (default 20 %/s) only slews the *externally set TECS lower throttle limit*. The TIMER → DONE code that sets that limit calls `Tiltrotor::get_forward_throttle()`, which returns false unless the vehicle is a vectored tiltrotor. | For Sage's 4+1 that special hand-off is skipped. The pusher step is TECS's own demand through `THR_SLEWRATE`; I did not trace it. Check with a log or SITL run. |
| O-11 | PARTIAL | POSITION1 builds a velocity profile `v = sqrt(max(0, d − pos2_dist)·2·Q_TRANS_DECEL + v_pos2²)`, bounded by `pos1_speed_limit` (and ≥ 2·Q_WP_SPD), feed-forward accel = −min(accel_needed, 2·Q_TRANS_DECEL). Velocity PID gains, jerk and the position-P are the `Q_P_*`/`Q_WP_*` groups (not read). | Repo's cascade (8.9) is structurally similar but not the same; `a_lim`, `K_p`, `K_v` are Sage tuning values, not ArduPilot constants. |

## Concrete code changes implied
1. `BaselineController` switch test: `d ≤ V_ground²/(2·a_plan) + 2·V_closing`; drop `speed_test="air"` from the baseline.
2. Insert the AIRBRAKE stage (1 s minimum, TECS pusher, hover-hold rotors, exit conditions above) between cruise and Position1.
3. `theta_limit`: start the ramp at `max(last_fw_nav_pitch, 0)`; add the nose-down envelope.
4. `theta_B` as a function of airspeed, `Q_BCK_PIT_LIM·(V_min/V)²`, active only for the NEW forward-throttle scheme.
5. Forward-transition fade: frozen `last_throttle`, linear, open-loop, floor 0.01.
6. 0.5 s rotor spool lag from rest; `MOT_SPIN_MIN` default 0.15.
