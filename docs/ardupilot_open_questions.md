## Concrete code changes implied
1. `BaselineController` switch test: `d ≤ V_ground²/(2·a_plan) + 2·V_closing`; drop `speed_test="air"` from the baseline.
2. Insert the AIRBRAKE stage (1 s minimum, TECS pusher, hover-hold rotors, exit conditions above) between cruise and Position1.
3. `theta_limit`: start the ramp at `max(last_fw_nav_pitch, 0)`; add the nose-down envelope.
4. `theta_B` as a function of airspeed, `Q_BCK_PIT_LIM·(V_min/V)²`, active only for the NEW forward-throttle scheme.
